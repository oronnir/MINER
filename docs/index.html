01 / Abstract

Identity is more than appearance.

Clothes-changing person re-identification is difficult because the same person can look radically different across outfits, environments, and camera views.

Clothes-Changing Person Re-Identification (CC-ReID) remains challenging due to drastic appearance shifts across outfits. Most prior works devise biometric signal-extraction heuristics to enhance inter-person variance, e.g., using segmentation masks, while leaving intra-person variance uncontrolled.

We present MINER, a simple model-agnostic framework that suppresses garment bias by contrasting hard examples and adaptively balancing dataset-dependent intra- and inter-person variance.

Extensive experiments show that MINER improves retrieval across CC-ReID benchmarks, achieving competitive performance across six clothes-changing benchmarks and ranking among the leaders in all three tracks of the open TVRID RGB-Depth ReID challenge.

02 / The method

Train on the differences that matter.

MINER couples a stochastic identity–outfit sampler with a multi-positive loss, then automatically allocates a fixed image budget between identities and samples per identity.

01 — INTER-PERSON

Find the look-alikes.

Soft-sample visually similar but distinct identities at the centroid level, presenting the model with challenging negatives.

Hard-negative identity mining
02 — INTRA-PERSON

Change the outfit.

Mine dissimilar cross-camera clothing pairs from each identity and align them using block-diagonal, multi-positive contrastive targets.

Hard-positive outfit mining
03 — ADAPTIVE CONTROL

Balance the batch.

Estimate gradient variance online to split the memory budget between the number of identities and examples per identity.

Closed-form variance controller
03 / How it works

One batch. Two complementary pressures.

Hard positives align the same identity across changed clothing. Hard negatives distinguish different identities that look alike. The contrastive supervision operates on the full query–gallery matrix.

04 / Experimental results

The best batch is dataset-dependent.

The number of identities and cross-outfit samples in a batch must compete for the same memory budget. PRCC and Celeb-L favor remarkably different allocations.

PRCC

Controlled clothing changes
5 : 17
A larger number of images per identity is preferred for PRCC; the risk-guided controller recovers an allocation near the measured optimum.

Celeb-L

Unconstrained in-the-wild variation
21 : 4
In-the-wild identities benefit from a larger identity budget, shifting the best split toward more people and fewer images per person.
