Modeling Inter- and Intra-Person Variance for Reidentification

01 / The idea

Learn from what makes ReID difficult.

Abstract

Clothes-changing person re-identification must match people across cameras despite drastic outfit changes. MINER focuses training on visually similar different people and visually dissimilar outfits of the same person.

It samples these hard cases stochastically at the centroid level, then applies a symmetric multi-positive contrastive loss. An online controller adjusts the number of identities and examples per identity using between- and within-person gradient variance.

MINER training mechanismschematic · not to scale
01 / BETWEEN IDENTITIES

Mine hard negatives

Choose different people with similar identity centroids.

02 / WITHIN AN IDENTITY

Mine hard positives

Choose dissimilar clothing centroids from the same identity across cameras.

03 / CONTRASTIVE TRAINING

Learn across outfits

Use all cross-outfit positives in a block-diagonal query–gallery loss.

Then adapt the batch: allocate a fixed image budget between m identities and n images per identity per side using online gradient-variance estimates.
02 / Variance-aware allocation

There is no universally optimal batch.

Different datasets have different ratios of between-identity to within-identity gradient variance. Their best allocations therefore fall at opposite ends of the same memory-budget frontier.

Read the plots: each point is a measured mAP result from the paper's fixed-allocation sweep. The green marker is the optimal allocation for that dataset.
